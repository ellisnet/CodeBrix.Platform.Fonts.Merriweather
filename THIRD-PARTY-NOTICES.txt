THIRD-PARTY SOFTWARE NOTICES AND INFORMATION

CodeBrix.Platform.Fonts.Merriweather is a CodeBrix-family redistribution of the
Merriweather font family, packaged as a .NET 10 NuGet library. Merriweather
covers the Latin and Cyrillic scripts but not Greek, Armenian or Georgian, so
this package additionally bundles three Noto Serif companion families that
supply those scripts. The package therefore incorporates four pieces of
third-party material:

  1. The Merriweather font family (SIL OFL 1.1) — the primary text face.
  2. The Noto Serif font family (SIL OFL 1.1) — the Greek companion.
  3. The Noto Serif Armenian font family (SIL OFL 1.1) — the Armenian companion.
  4. The Noto Serif Georgian font family (SIL OFL 1.1) — the Georgian companion.

The CodeBrix-authored parts of this package — the `.csproj`, the
buildTransitive `.targets` file, the `.ttf.manifest` JSON files, the
`CODEBRIX-DEVELOP.json` descriptor, the `.uprimarker` marker, the
documentation, and the packaging metadata — are original to the CodeBrix family
and contain no third-party source code. They are released, together with the
bundled font files, under the SIL Open Font License, Version 1.1, the same
license as the fonts. The full license text is bundled with this repository as
`OFL.txt` at the repository root and is also packaged inside the produced NuGet
under the same name.

   Modifications made during redistribution:
     - Only the six weights Light (300), Regular (400), Medium (500),
       SemiBold (600), Bold (700), and ExtraBold (800) are shipped as static
       instances; the upstream Black (900) static instances are not included.
       (That weight remains reachable through the bundled variable font.)
       Merriweather publishes no Thin or ExtraLight static instances upstream.
     - Only the 24pt optical size is shipped as static instances. Merriweather
       publishes five optical sizes (24, 36, 48, 96 and 120 pt), but the
       CodeBrix font-manifest schema addresses fonts by style, weight and
       stretch only and has no optical-size dimension, so a single optical size
       is shipped. 24pt was chosen as the closest static to the variable font's
       own `opsz` default of 18. The upstream `_24pt` filename token is stripped
       so the filenames match the convention used across the CodeBrix font
       packages. No `.ttf` binary content was altered.
     - The upstream upright variable font
       `Merriweather-VariableFont_opsz,wdth,wght.ttf` was renamed to
       `Merriweather.ttf`. No `.ttf` binary content was altered.
     - The separate upstream italic variable font
       `Merriweather-Italic-VariableFont_opsz,wdth,wght.ttf` is not included;
       italic styles are provided through the static instances.

   The full SIL Open Font License Version 1.1 text is reproduced in
   `OFL.txt` at the root of this repository, and is also packaged inside
   the produced NuGet under the same name.
